# ねこものしりクイズ

ねこについての〇×クイズです。`cat-quiz.csv` にある30問からランダムに10問を出題します。スマートフォンにも対応しています。

## 起動方法

ブラウザーからCSVを読み込むため、HTMLファイルを直接開くのではなく、リポジトリのルートでローカルWebサーバーを起動してください。

```sh
python -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開きます。スマートフォンから試す場合は、パソコンと同じWi-Fiに接続し、`localhost` の代わりにパソコンのローカルIPアドレスを指定してください。

## CSV形式

UTF-8のCSVで、見出しは `question,answer,explanation` です。答えには `〇` または `×` を指定します。
